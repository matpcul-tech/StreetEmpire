# Street visual demo assets

These files are fetched only when the page is opened with `?demo=street`.
The live game (`src/main.js`) never requests this folder.

- `tex/` CC0 PBR maps from ambientCG, resized to WebP with mipmaps generated at runtime.
- `models/crew.glb` MakeHuman/MPFB CC0 body, simplified and meshopt compressed.
- `models/ual-loco.glb` Quaternius Universal Animation Library idle, walk, jog and sprint clips, no character meshes.
